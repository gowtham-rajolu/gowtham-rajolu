## About

I'm **Gowtham Rajolu**, a software engineer interested in the intersection of **software development, cybersecurity, and artificial intelligence**.

I enjoy moving between the application layer and the systems underneath it: designing APIs, building full-stack applications, experimenting with computer vision and AI workflows, and learning network and Linux security through hands-on labs.

- **Software engineering:** full-stack applications, backend APIs, databases, and real-time systems.
- **Cybersecurity:** networking, Linux, packet analysis, web security fundamentals, and practical labs.
- **AI development:** Python-based applications, LLM integrations, automation, and computer vision.
- **Engineering mindset:** understand the problem, build a working solution, test it, and improve it.
